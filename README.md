# Christmas Tree RGB Bauble
A while ago I ordered a rell of 1k 1.2x1.2mm RGB LEDs for $0.002 each and I wanted to use them for something.
The circuit has provisions for a very small SEPIC converter that could be used as a constant current charging source for a built in battery.

I didn't get a chance to port my code from [my cheap power supply project](https://github.com/BogdanTheGeek/CCCCPPPS), but the bauble ended up very nice.

This was my first time programming charlieplexed animations so the code may not be efficient, but it's quite nice to work with I think.

This design was optimised solely to be easy to make on my CNC mill and etch with my home setup, which is why it's in a frame.
